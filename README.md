# PrevisaoTempo

A cross-platform mobile and desktop application built with **.NET MAUI** and **C#** that provides real-time weather forecasting based on the user's location.

## Features
- **Real-time Data:** Fetches up-to-date weather information including temperature, humidity, and conditions.
- **REST API Integration:** Consumes external Weather Web Services using asynchronous HTTP requests (`HttpClient`).
- **JSON Parsing:** Efficiently deserializes API responses into structured C# data models.
- **Modern UI:** Built using XAML with responsive design principles for cross-platform support.

## Tech Stack & Concepts
- **Framework:** .NET MAUI (Multi-platform App UI)
- **Language:** C# / XAML
- **Networking:** Asynchronous Programming (`async/await`), `HttpClient`
- **Data Handling:** JSON Deserialization, RESTful API Integration
